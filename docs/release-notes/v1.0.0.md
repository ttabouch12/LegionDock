The first public release of **LegionDock**: plug your Lenovo Legion tablet into a TV and it becomes a console.

### Highlights
- **Four TV modes**: Console, Desktop (Lenovo PC mode with adjustable scale), Media and Mirror, each with its own settings.
- **Tablet screen off while docked**, without pausing apps.
- **Automatic undo**: resolution, UI size, refresh rate, rotation, audio, home screen, Bluetooth and charging go back when you unplug.
- **Controller tools**: Guide button quick menu, Select + Start, virtual mouse, handheld mode.
- **Game profiles**: per-game refresh rate, FPS limit, overlay and memory cleanup.
- **Battery care**: bypass charging while docked.
- **Switch save sync** between Eden and Citron, with automatic backups.
- **Capability detection**: features your tablet doesn't support are hidden.
- **Rescue script** (`tools/rescue.sh`) for the rare case the tablet gets stuck.

### Install
1. Install and start [Shizuku](https://shizuku.rikka.app/download/).
2. Install `LegionDock-1.0.0.apk` below.
3. Open it and follow **Finish setup**. Full guide: [docs/SETUP.md](https://github.com/ttabouch12/LegionDock/blob/main/docs/SETUP.md).

Tested on the Legion Y700 Gen 3 (TB321FU, ZUXOS 1.5, Android 16). Reports from other models are very welcome.

Requires Android 11+.
